# BankManager

Проэкт имитирует работу простейшего банковского приложения. Разработан на языке С# и называется BankManager

## 📋 Описание

BankManager - консольное приложение, имееющее удобный текстовый интерфейс для взаиможействием с пользователем.
В нём можно регестрировать аккаунты пользователей и производить действия как со своим аккаунтом так и с другими.
Проект разработан для закрепления знаний в области ООП и Git.

## 🚀 Функциональность

- Создание аккаунта
- Вход / Выход из аккаунта
- Пополнение счёта
- Перевод на счёт
- История операций
- Выйти из приложения 

## 🛠️ Технологии

- C#
- .NET 8
- Git
